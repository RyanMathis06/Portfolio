# __Grammys Website Performance__

For this project I analyzed the difference in performance of 2 Grammy's websites. The first one called Grammys, had both the Grammys and the Recording Academy information in 1 website while the Recording Academy represents the website where they split into 2 websites. The goal of this project is to figure out which form of website has higher performance based on pages per session, bounce rate (percentage of users that come to the website and never interact with the page), average time on site, and percentage of mobile visitors.
